# EG Visualizer — corrected standalone version

## Run
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Local URL printed by Vite (usually http://localhost:5173).

## Verify
Run `npm run build` to type-check and build.

## Notes
Question 7 is implemented, questions 1–6 and 8–10 are placeholders.
The source question specifies 40 mm triangular side, axis parallel to HP and VP. The reference diagram additionally assumes 60 mm axis length.
SVG is geometrically proportional, not a guaranteed 1:1 printed output.
