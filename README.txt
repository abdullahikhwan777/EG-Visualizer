Trace desktop and mobile installation update

Upload index.html, site.webmanifest and all three trace-icon PNGs to the same GitHub Pages folder as your existing index.html. Retain all other repository files. If you have already uploaded the mobile update, replace index.html only.

Desktop: click Install Trace on Desktop on the login screen or account panel. Confirm the browser install prompt if offered; otherwise use the browser-menu instructions. Windows users can also download a .url link in the help dialog and move it to Desktop (opens in default browser).
Android and iPhone: the existing Add Trace to Home Screen button remains.
No offline mode or service worker. Internet required for Google sign-in. Browser installation and Google login in standalone windows need live testing.
